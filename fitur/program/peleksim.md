# Peleksim

| Nama | Keterangan |
| ---- | ---------- |
| Peleksim | Lexer / Lexical Analyzer / Scanner (program atau komponen pengeksekusi yang memproses kode program) |
| Peleksiman | Leksing / Lexing / Analisis Leksikal (proses memecah baris kode sumber menjadi unit-unit bermakna) |
| Leksim | Lexeme (unit atau deretan karakter terkecil dalam kode yang cocok dengan pola token tertentu, seperti jk, x, 100, atau +) |
